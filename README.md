# Vernika Workflows

Vernika Workflows brings three SEO and publishing workspaces together in a unified web suite:

- **Automated Blogger** (`/`) — Generate, review, schedule, and publish SEO-structured articles and branded banners to Google Blogger.
- **Blogger SEO Indexer** (`/indexer/`) — Submit URL batches and verify indexing coverage using managed Google service accounts.
- **SEO PDF Studio** (`/seo-pdf/`) — Build bulk SEO PDFs, publish landing assets, and check search rankings.
- **Admin Console** (`/admin/`) — Manage customer profiles, tool assignments, subscription expiry windows, active sessions, and saved integration keys.
